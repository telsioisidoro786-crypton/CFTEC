
## Extensão CMS/Admin

- [x] Painel `/admin` responsivo com sidebar, header, estado online, logout e navegação por abas.
- [x] Dashboard com métricas de softwares, mídias, serviços e contactos, pedidos recentes, saúde do workspace e acções rápidas.
- [x] Gestão de serviços, gestão de mídias com drag-and-drop/pré-visualização, catálogo de softwares/downloads, modal de novo software e definições.
- [x] Esquema MySQL aditivo para `admins`, `services`, `media`, `softwares` e `contacts`, mantendo campos, estados e timestamps do pedido.
- [x] API administrativa para resumo, contactos, serviços, mídias e softwares, com seed inicial do catálogo CFTEC.
